# Бей крота — редактор учебной игры

Визуальный редактор работает локально в браузере и хранит проект в `localStorage`.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно `http://localhost:5173`).

## Возможности

- живой предпросмотр и полноценный тестовый режим;
- настройка фона, нор, персонажей, предмета удара и игровых правил;
- случайные появления и ручной сценарий;
- четыре типа учебных заданий;
- загрузка PNG, JPG, WebP и анимированных GIF;
- undo/redo и автоматическое локальное сохранение;
- импорт/экспорт JSON;
- экспорт автономной HTML-игры и код iframe для Genially.
